## 四、如何复核

本包全部为文本交付，复核不需要任何环境：

1. **正文**：直接打开两篇 `.md`，文首表格给出平台、时间、链接与摘要；
2. **数据**：对照 `数据记录.md` 中的后台回显块，字段与公众号「内容分析 → 单篇数据」一致；比率指标已注明分母；
3. **数字一致性**：正文里出现的每个数字（5/5、10/12、综合 90、24 条、19 条、40+ 格式、412/703 等）都能在 C4 / C6 交付物或数据记录中找到出处（对照表见 `拿来说明.md` 2.5 节）；
4. **AI 记录**：每轮含指令要点、产出问题、人的改动；失败轮次单独建索引，可抽查。
